GALLERY PHOTOS
==============
Put your photos in this folder, then list them in js/config.js (section 6).

The four photo-N.jpg files here are labelled PLACEHOLDERS. Replace them by saving
your own picture with the same file name, or add new files and new lines in config.js.

Tips
- JPG or WebP, around 1200 pixels on the longest side, under ~400 KB each.
- Avoid spaces in file names (use photo-1.jpg, not "My photo 1.jpg").
- Always write a short description (alt text) in config.js so screen readers can describe it.
